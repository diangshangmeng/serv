# 集成测试指南

## 概述
本目录包含项目的集成测试。集成测试需要完整的数据库和Redis环境。

## 运行测试

### 前置条件
1. MySQL 数据库运行在 localhost:3306
2. Redis 运行在 localhost:6379
3. 创建测试数据库 `voucher_platform_test`

### 运行所有集成测试
```bash
go test -v ./tests/...
```

### 运行特定测试
```bash
go test -v -run TestAuthAPI_Login ./tests/...
```

## 注意事项

1. 集成测试会修改数据库数据，请使用专门的测试数据库
2. 某些测试可能需要较长时间运行（如超时测试）
3. 测试环境应该与生产环境隔离
